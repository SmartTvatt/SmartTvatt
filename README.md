🚀 Starta SmartTvätt‑projektet (MERN)
1. Installera förutsättningar
Node.js (18+)

Git

MongoDB (lokalt eller Atlas)

2. Klona projektet
bash
git clone <repo-url>
cd SmartTvatt
3. Backend
bash
cd Backend
npm install
Skapa .env
Code
MONGO_URI=mongodb://localhost:27017/smarttvatt
PORT=3001
Starta backend
bash
npm run dev
Backend kör på: http://localhost:3001

4. Frontend
bash
cd ../Frontend
npm install
npm run dev
Frontend kör på: http://localhost:5173

5. Köra hela appen
Starta backend

Starta frontend

Öppna webbläsaren på localhost:5173
